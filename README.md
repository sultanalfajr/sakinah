# سَكِينَة — أصواتٌ للنوم وقصصُ تُروى ببطء

تطبيق ويب للتأمل أثناء النوم و ASMR، بالعربية بالكامل (RTL). مشاهد صوتية محيطة **تُولَّد رقمياً لحظياً** عبر Web Audio API — بلا أي تسجيلات — فتتكرّر بلا بدايةٍ ولا نهاية، داخل سماءٍ ليلية حية تتنفّس معك.

## المزايا

- **اختيار الليلة (Night Picker)** — ثلاث ليالٍ جاهزة كل واحدة ٤٥ دقيقة: مطرٌ على ضوء القمر، شاطئُ منتصف الليل، كابينةٌ في الغابة. بضغطة واحدة يُضبط الخلاط ويبدأ المؤقت.
- **مكتبة المشاهد الصوتية** — المطر، الغابة، المحيط، المقهى، المدفأة، همهمة البيانو — كلها مُخلَّقة إجرائياً (ضوضاء ملوّنة + مرشحات + LFOs + مجدولات عشوائية).
- **خلاط المشهد الصوتي** — ٧ أشرطة شدّة تُمزج فوق بعضها: مطرٌ فوق مدفأة، ورياحٌ فوق كل شيء.
- **قصص النوم** — قصص مضمّنة بصوتٍ جاهز + مولّد قصص بالذكاء الاصطناعي (اختياري)، مع رواية صوتية وتمريرٍ تلقائي بطيء للقراءة.
- **القرآن الكريم** — تلاوات مختارة للنوم من ٦ قرّاء، من مصادر مجانية مفتوحة بلا أي مفتاح، مع تكرارٍ ومزجٍ مع الأصوات المحيطة وتلاشٍ تلقائي مع المؤقت — ويمكن رفع ملفات قارئك الخاص لتعمل بلا إنترنت.
- **مؤقت النوم** — ٣٠ / ٦٠ / ٩٠ دقيقة، يتلاشى الصوت ببطءٍ طويل في الدقيقة الأخيرة حتى الصمت، وتخفت النجوم في آخر ٥ دقائق.
- **حساب النوم** — سلسلة الليالي المتتالية، إجمالي الدقائق، الليالي الهادئة، مخطط آخر ٧ ليالٍ، وسجل الجلسات (Prisma + SQLite).
- **سماء حيّة** — نجوم تتلألأ وشهب عابرة، وهلالٌ يعبر قوس السماء خلال ١٢ ساعة تماماً.
- **وضع الانغماس** — زرّ القمر يخفي كل الواجهة وتبقى السماء والصوت فقط (للخروج: Esc).
- **توهج المؤشر** — أثر ضوءٍ خافت يتبع الفأرة على الواجهة الداكنة.

## التقنيات

| الطبقة | الأداة |
|---|---|
| الإطار | Next.js 16 (App Router) + TypeScript |
| الواجهة | Tailwind CSS 4 + shadcn/ui + Framer Motion |
| الصوت | Web Audio API (توليد إجرائي بالكامل) |
| قصص النوم | توليد نصّي بالذكاء الاصطناعي + TTS (محلياً عبر z-ai-web-dev-sdk، أو أي مزوّد متوافق مع OpenAI عبر متغيرات البيئة) |
| البيانات | Prisma ORM + SQLite محلياً / Cloudflare D1 في النشر |
| التخزين الصوتي | القرص محلياً / Cloudflare R2 في النشر |
| الاستضافة | Cloudflare Workers (عبر @opennextjs/cloudflare) |

## التشغيل محلياً

```bash
# 1) تثبيت الحزم
bun install

# 2) إعداد متغير البيئة
echo 'DATABASE_URL=file:./db/custom.db' > .env

# 3) إنشاء قاعدة البيانات
bun run db:push

# 4) تشغيل خادم التطوير
bun run dev
```

ثم افتح `http://localhost:3000`.

> ملاحظة: الصوت يبدأ بعد أول تفاعل من المستخدم (سياسة المتصفحات) — اضغط أي مشهدٍ صوتي ليبدأ.

## النشر على Cloudflare

التطبيق مهيّأ بالكامل لـ Cloudflare Workers: قاعدة البيانات **D1**، ملفات الصوت **R2**، والبناء عبر **OpenNext**.

### 1) إنشاء الموارد

```bash
bun install
bunx wrangler login          # تسجيل الدخول لحساب Cloudflare
bunx wrangler d1 create sakinah-db       # انسخ database_id من النتيجة
bunx wrangler r2 bucket create sakinah-audio
```

ضع `database_id` الحقيقي في `wrangler.jsonc` (مكان المعرّف الصفري).

### 2) تهيئة قاعدة D1

```bash
bun run cf:db:remote         # ينفّذ d1/0001_init.sql على القاعدة البعيدة
```

### 3) مفاتيح الذكاء الاصطناعي — اختيارية تمامًا

**التطبيق يعمل بالكامل بلا أي مفتاح API** 🎉

| الميزة | بلا مفتاح | مع مفتاح |
|---|---|---|
| كل الأصوات المحيطة والخلاط والمؤقت | ✅ يعمل (توليد إجرائي محلي) | ✅ |
| القصص المضمنة + قصص المجموعة الجاهزة — صوت كامل | ✅ MP3 مضمن | ✅ |
| التلاوات القرآنية | ✅ مصادر مجانية عبر الإنترنت | ✅ |
| توليد قصة جديدة بموضوعك | قصة جاهزة من المجموعة | توليد حيّ بالذكاء الاصطناعي |
| رواية صوتية لقصص جديدة | رسالة ودية تطلب مفتاحًا | ✅ |

> لإعادة توليد الصوت المضمن لاحقًا: شغّل `bun scripts/prebuild-audio.ts` (يتطلب بيئة بها SDK) ثم أضف المعرفات إلى `PREBUILT_AUDIO_IDS` في `src/lib/builtin-stories.ts`.

## القرآن الكريم

قسم التلاوة يعمل فورًا بلا أي إعداد: ٦ قرّاء (العفاسي، المعيقلي، الحصري، المنشاوي، السديس، عبد الباسط) و١٦ سورة مختارة للنوم.

**ترتيب المصادر** — يجرّبها المشغّل تباعًا إن فشل أحدها:

1. ملفاتك المحلية: `public/quran/{معرّف-القارئ}/{رقم-السورة}.mp3`
2. `cdn.mp3quran.net` — مكتبة mp3quran المفتوحة
3. `cdn.islamic.network` — مشروع القرآن المفتوح

**لإضافة قارئك الخاص أو العمل بلا إنترنت:** ضع ملفات MP3 في
`public/quran/{معرّف-القارئ}/{رقم-السورة}.mp3` (مثل `public/quran/maher-muaiqly/67.mp3`) —
راجع `public/quran/README.md`. الملفات المحلية تُنشر تلقائيًا مع الـ Workers
كأصول ثابتة (الحد 25MB للملف على Cloudflare — استخدم معدل بتّ أقل للسور الطويلة).

إن أردت تفعيل التوليد الحيّ لاحقًا، يحتاج مزوّداً متوافقاً مع OpenAI (z.ai أو OpenAI أو Groq أو OpenRouter…):

```bash
bunx wrangler secret put AI_API_KEY      # مفتاح المزوّد
bunx wrangler secret put AI_BASE_URL     # مثل https://api.z.ai/api/paas/v4 أو https://api.openai.com/v1
```

واختار النماذج من `vars` في `wrangler.jsonc` (`AI_CHAT_MODEL` / `AI_TTS_MODEL` …).

### 4) النشر

```bash
bun run cf:deploy            # بناء + نشر إلى workers.dev
```

أو اربط مستودع GitHub من لوحة Cloudflare (Workers & Pages ← Create ← Connect to Git) وأمر البناء:
`bunx opennextjs-cloudflare build` — وسيُنشر تلقائياً مع كل push.

### تجربة محلية ببيئة Cloudflare

```bash
bun run cf:db:local          # تهيئة D1 محلية
bun run cf:preview           # تشغيل workerd محلياً على :8787
```

لضبط مفاتيح AI في المعاينة المحلية: انسخ `.dev.vars.example` إلى `.dev.vars` وعبّئ القيم.

### حدود الخطة المجانية

| المورد | المجاني شهرياً |
|---|---|
| Workers | ١٠٠ ألف طلب/يوم |
| D1 | ٥ GB تخزين + ٥ مليون صف يومياً |
| R2 | ١٠ GB تخزين |

## البنية

```
src/
├── app/
│   ├── page.tsx              # الصفحة الوحيدة — كل الأقسام
│   └── api/                  # الجلسات، الملف الشخصي، القصص + روايتها الصوتية
├── components/               # السماء، الانغماس، المكتبة، الخلاط، المؤقت…
├── lib/ai.ts                 # مهايئ AI مزدوج (SDK محلياً / OpenAI-compatible للنشر)
├── lib/audio-store.ts        # مخزن صوتي مزدوج (قرص محلياً / R2 في النشر)
├── lib/audio/engine.ts       # محرك التوليد الصوتي الإجرائي
├── lib/quran.ts              # فهرس التلاوات: القرّاء والسور والمصادر المجانية
└── lib/db.ts                 # عميل Prisma مزدوج (SQLite محلياً / D1 في النشر)
prisma/schema.prisma          # Profile / Session / Story
d1/0001_init.sql              # ترحيل قاعدة D1
wrangler.jsonc                # إعدادات Cloudflare (D1 + R2 + المتغيرات)
```
