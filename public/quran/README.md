# ملفات التلاوة المحلية (اختياري)

يمكنك إضافة تلاوات قارئك المفضّل لتعمل **بلا إنترنت** وبأعلى أولوية قبل
أي مصدر خارجي.

## الصيغة

ضع كل قارئ في مجلدٍ باسم معرّفه، وسمِّ الملفات برقم السورة:

```
public/quran/mishary-alafasy/1.mp3      ← سورة الفاتحة
public/quran/mishary-alafasy/67.mp3     ← سورة الملك
public/quran/maher-muaiqly/36.mp3       ← سورة يس
```

المعرّفات المطابقة للقرّاء الموجودين في التطبيق:

| معرّف المجلد          | القارئ               |
| --------------------- | -------------------- |
| `mishary-alafasy`     | مشاري راشد العفاسي  |
| `maher-muaiqly`       | ماهر المعيقلي        |
| `mahmoud-husary`      | محمود خليل الحصري   |
| `muhammad-minshawi`   | محمد صديق المنشاوي  |
| `abdulrahman-sudais`  | عبد الرحمن السديس   |
| `abdulbasit-murattal` | عبد الباسط عبد الصمد |

يمكنك أيضًا إنشاء مجلد باسم جديد (مثل `my-reciter`) وسيُستخدم بعد إضافة
معرّفه إلى القائمة في `src/lib/quran.ts`.

## ملاحظات

- الصيغة المدعومة: MP3، وسمِّ الملف برقم السورة دون أصفار (`1` إلى `114`).
- على Cloudflare Workers الحد الأقصى لحجم الملف الثابت 25MB — اختر معدّل
  بتّ أقل للسور الطويلة (128kbps ≈ 16KB لكل ثانية).
- التطبيق يجرّب الملف المحلي أولًا، فإن لم يوجد انتقل تلقائيًا إلى المصادر
  المجانية على الإنترنت (mp3quran ثم islamic.network).
